# Model card — TeleopQ v1 BC policy (GR-1 pick-and-place)

| Field | Value |
|---|---|
| Model | robomimic BC-RNN, low-dimensional observations (config `bc_rnn_low_dim_gr1t2`, from Isaac Lab) |
| Checkpoint | `model_epoch_2000.pth` (run folder `bc_rnn_low_dim_gr1t2/20261114225335/`) |
| Task | `Isaac-PickPlace-GR1T2-Abs-v0`: Fourier GR-1 humanoid picks an object from a table and places it at a target |
| Inputs | Robot state (joint positions, wrist poses, hand joints, head joints, link states) and object pose, as recorded by Isaac Lab |
| Outputs | 36-D absolute action: two wrist poses (position + quaternion) and 22 hand-joint targets, normalized to [−1, 1] |
| Training data | 300 demos (39,662 samples) generated by Isaac Lab Mimic from NVIDIA's 5 annotated seed demos |
| Training | 2000 epochs, robomimic 0.4.0, PyTorch 2.10, one NVIDIA L40S; ~37 min |
| Action scaling | min −1.7409957647323608, max 1.3797252178192139 (needed at evaluation) |
| Evaluation | 50 closed-loop rollouts, horizon 400 steps, randomized object placement |
| **Result** | **48/50 = 96% success** (95% Wilson interval 86.5–98.9%) |

## Intended use

A reference policy for the TeleopQ course project (CMPE 249, Fall 2026): the clean-data baseline that policies
trained on degraded or curated demonstrations are compared against. Simulation only.

## Not intended for

Real robots, other tasks, or any safety-relevant use. Trained and evaluated in simulation only.

## Limitations

- Trained on synthetic demos amplified from 5 clean expert seeds; no human-operator variability.
- One training seed and one evaluation run; the interval above reflects only rollout sampling.
- Only the final checkpoint was evaluated.
- Uses privileged simulator state (exact object pose), not camera images.
